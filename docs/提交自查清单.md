## I 提交前 30 分钟（Last mile）

1. `git status --short` 必须为空；不为空就先提交。
2. 打 tag：`git tag -a v1.0-submit -m "省赛提交版本"`，并 `git push --tags`。
3. 仓库设为**公开**（或按赛事要求给评审只读权限），确认评委未登录也能 clone。
4. 在提交页粘贴：仓库地址、README 直链、技术文档 PDF 直链、视频链接（若需外链，用可匿名访问的地址）。
5. 上传包内自查：`node_modules` 不含、`.next` 不含、`.env.local` 不含。
6. 用浏览器**退出登录**后再点一遍所有链接（模拟评委）。
7. 记录提交回执截图，存入 `_shots/`（不进仓库）。

## K 已知局限（主动写出来，比被评审问出来好）

- 仅支持 CSV（支付宝 / 微信 / 银行），PDF 与截图账单未做 OCR。
- 分类是关键词规则，长尾商户会落到「其他」。
- 只分析流水最多的单月，没有多月对比。
- 模型质量依赖上游；语气会随模型波动，数字不会。
- 无账号体系、无云端同步——这是隐私取舍，不是遗漏。
